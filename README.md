# GETO · Private Domain

Редактируемый сайт из загруженного архива находится в [`website/`](website/). Сам ZIP сохранён как исходная копия, рабочая версия развивается отдельно.

```sh
cd website
npm ci
cp .env.example .env.local
npm run dev
```

Открыть http://localhost:3000. Без серверного API-ключа доступны сценарный чат и локальная галерея. Для свободных ответов и новых иллюстраций см. [настройку и ограничения](website/README.md).
