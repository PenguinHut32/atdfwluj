# GETO · Private Domain

Атмосферный неофициальный фан-проект о Сугуру Гето. Главная с многослойным параллаксом, три тематических приглашения и одноконтактный мессенджер на App Router и TypeScript.

## Запуск

Требуется Node.js 20.9+ и npm. Проверено на Node.js 26.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Открыть `http://localhost:3000`. Для production:

```sh
npm run build
npm start
```

Интерфейс, метаданные, иконка и страницы ошибок имеют собственное оформление. Индикатор разработки и заголовок `X-Powered-By` отключены. Технические имена зависимостей и служебные маршруты сборщика остаются частью используемого фреймворка.

## Настоящие ответы ИИ

В `.env.local` или секретах хостинга задать:

```dotenv
OPENAI_API_KEY=your-secret-key
OPENAI_MODEL=gpt-4.1-mini
ENABLE_IMAGE_GENERATION=false
```

Перезапустить сервер после изменения переменных. Ключ используется **только сервером**, не вводится в интерфейсе и не включается в клиентскую сборку. Провайдер должен поддерживать Chat Completions и строгую JSON-схему ответа. Действующий ключ и доступ к модели не поставляются с проектом.

Без ключа работает явно обозначенный **деморежим со сценарными репликами**, не имитация работающей языковой модели. Неверный ключ, недоступность провайдера или исчерпание квоты возвращают понятную ошибку, а не незаметную подмену на демо.

Образ поддерживает спокойную, высокомерную манеру Гето, канонический контекст, наставничество, философский спор и инициативные вопросы. При прямом вопросе персонаж честно поясняет, что это фанатская ИИ-интерпретация. Идеология вымышленного злодея не используется для травли реальных людей.

## Изображения

- Без генерации: локальный портрет, авторская иллюстрация храма и абстрактная проклятая энергия.
- `ENABLE_IMAGE_GENERATION=true`: запросы изображений используют платный `gpt-image-1`, 1024×1024 PNG, `quality: low`. Не включайте без проверки прав доступа и бюджета аккаунта.
- Изображения открываются в полноэкранном просмотре и скачиваются.
- Сгенерированные PNG **не сохраняются в localStorage**, чтобы не исчерпать квоту браузера. Сохраните их отдельно до обновления/закрытия страницы. Текст и локальные изображения сохраняются.
- Живые вызовы провайдера требуют отдельной проверки с вашим ключом; автоматические тесты используют фиктивные ответы, не расходуют деньги.

## Мессенджер

Первое сообщение: «Привет. Ты хотел что-то?»

Работают отправка Enter / новая строка Shift+Enter, подсказки для начала разговора, индикатор подготовки ответа, поиск по переписке, поиск единственного контакта, эмодзи, изображения, профиль, экспорт текста и удаление истории с подтверждением. Ошибки возвращают неотправленный текст в поле ввода. Повторные отправки во время запроса блокируются. Запрос отменяется при уходе со страницы или сбросе диалога.

Весь текст текущего диалога передаётся модели. Ограничения: до 150 сообщений в запросе, до 6000 символов на сообщение, до 100 000 символов истории. При превышении возвращается ошибка, история не обрезается скрытно. Перед новым диалогом можно скачать старый. Постоянной серверной памяти, синхронизации устройств и базы пользователей нет.

## Приватность и публикация

- История хранится открытым текстом только в текущем браузере. Она доступна другим пользователям того же профиля браузера. Это не сквозное шифрование.
- В live-режиме весь текст отправляется OpenAI. Не передавайте секреты и чувствительные персональные данные.
- «Закрытое пространство» — художественный приём, **не авторизация**. Перед публичной публикацией платного API добавьте авторизацию и общие квоты на шлюзе.
- Встроенные лимиты: 20 запросов/минуту и 3 генерации/10 минут на клиента, до 4096 клиентов в памяти. Перезапуск, несколько серверов и вытеснение записей сбрасывают лимиты. Это вспомогательная защита, не надёжный контроль расходов.
- Доверенный reverse proxy должен сохранять публичный `Host` и **перезаписывать** `X-Forwarded-For`. Иначе лимиты можно обойти подменой заголовка; без IP все клиенты используют общую корзину.
- Проверяются Origin и Sec-Fetch-Site. Это защита от браузерных cross-origin запросов, не аутентификация для сторонних HTTP-клиентов.
- Ограничены размер тела, история, ответ провайдера и PNG. Есть дедлайны и безопасные ошибки без логирования ключей и переписки.
- Используйте HTTPS. Перед коммерческим выпуском получите права на персонажа и иллюстрацию или замените её материалом с собственной лицензией. Наличие ссылки на источник не заменяет разрешение.

## Производительность и доступность

Статическая главная, локальные шрифты (включая японский поднабор), оптимизированный WebP, SVG вместо тяжёлого видео и WebGL. Параллакс использует MotionValue без React-рендера на каждый кадр. Анимации ограничены transform/opacity, появления запускаются один раз; учитывается `prefers-reduced-motion`. Звук по умолчанию выключен и приостанавливается в скрытой вкладке. Адаптивная компоновка, семантические заголовки, подписи кнопок, клавиатурное управление и нативные модальные окна.

Абсолютную плавность на всех средних устройствах нельзя подтвердить проверкой в одном браузере; перед выпуском необходимы замеры на целевых телефонах.

```sh
npm run lint

npm test
npm run build
```

Тесты покрывают валидацию, демо, полную передачу контекста, mocked live-ответы и генерацию, лимиты, Origin/Host, ошибки провайдера, размеры, дедлайны и восстановление истории. Проверены в Chrome: переход из приглашения, отправка/ответ, запрос изображения, просмотр, восстановление истории и мобильная компоновка.
